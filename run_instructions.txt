             AI-Powered Medicine Assistant System Setup & Run Instructions
             (Bilingual Support: Urdu Default with English Toggle)
========================================================================

HOW TO RUN ON ANY NEW PC / LAPTOP (SUBMISSION GUIDE)
------------------------------------------------------------------------

METHOD 1: ONE-CLICK AUTO-SETUP & LAUNCH (RECOMMENDED)
------------------------------------------------------------------------
Just double-click "run_app.bat" in the project folder!
- It automatically detects your Python installation.
- It automatically creates the virtual environment ("venv").
- It automatically downloads and installs all required libraries 
  (OpenCV, YOLOv8, EasyOCR, Piper Neural TTS, Pygame, etc.).
- It immediately launches the application!
- On all future runs, it starts in 1-2 seconds with zero re-downloading.

------------------------------------------------------------------------
METHOD 2: MANUAL COMMAND-LINE INSTALLATION (IF PREFERRED)
------------------------------------------------------------------------
Open Command Prompt or PowerShell in this project folder:

1. Create a Python Virtual Environment:
   python -m venv venv

2. Activate the Virtual Environment:
   * Windows (Command Prompt):
     venv\Scripts\activate.bat
   * Windows (PowerShell):
     venv\Scripts\Activate.ps1
   * macOS / Linux:
     source venv/bin/activate

3. Install All Required Dependencies in One Go:
   pip install --upgrade pip
   pip install -r requirements.txt

4. Run the Main Application:
   python main.py

5. (Optional) Run the Full System Test Suite to Verify:
   python test_runner.py
   python test_suite.py

------------------------------------------------------------------------
PREREQUISITES
------------------------------------------------------------------------
1. Python 3.9, 3.10, or 3.11 installed.
   Download link: https://www.python.org/downloads/
   * CRITICAL: Check the box "Add Python to PATH" during Python installation!

2. Internet Connection (First Run Only):
   Needed only on the very first run to download the pip packages from 
   requirements.txt and EasyOCR text models.
   Once downloaded, the entire system runs 100% OFFLINE!

------------------------------------------------------------------------
LANGUAGE & ACCESSIBILITY FEATURES (URDU & ENGLISH)
------------------------------------------------------------------------
- Default Language: Urdu (اردو) is enabled by default.
- Spoken Voice Guidance:
  Natural Pakistani Urdu voice powered by offline Piper Neural ONNX 
  speech engine.
- Instant Language Toggle:
  Press the "T" key or click the language button to toggle between 
  Urdu and English anytime.

------------------------------------------------------------------------
KEYBOARD SHORTCUTS
------------------------------------------------------------------------
- [T]       : Toggle language between Urdu and English (زبان تبدیل کریں)
- [SPACE / C]: Capture bottle/medicine label (دوا کا لیبل اسکین کریں)
- [R]       : Retry / Return to live camera feed (دوبارہ کوشش کریں)
- [I]       : Internet fallback search (آن لائن انٹرنیٹ تلاش)
- [U]       : Select Local USB Webcam (لوکل ویب کیم)
- [W]       : Select Wireless IP Camera (وائرلیس آئی پی کیمرا)
- [V]       : Verify camera connection (کیمرا چیک کریں)
- [L]       : Launch dashboard from setup wizard (ڈیش بورڈ شروع کریں)
- [Q]       : Shutdown system workspace (سسٹم بند کریں)
