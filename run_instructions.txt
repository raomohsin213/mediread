========================================================================
             AI-Powered Medicine Assistant System Setup & Run Instructions
             (Bilingual Support: Urdu Default with English Toggle)
========================================================================

Follow the steps below to setup and run this project on any other PC or laptop.

------------------------------------------------------------------------
Prerequisites
------------------------------------------------------------------------
1. Python Installed:
   Ensure Python 3.9, 3.10, or 3.11 is installed on the target machine.
   * Make sure to check the box "Add Python to PATH" during installation.
   * Download link: https://www.python.org/downloads/

2. Internet Connection (First Run Only):
   An internet connection is required for the first run so that the AI engines
   (EasyOCR) can download their offline language recognition models. 
   Subsequent runs can be performed completely 100% offline.

------------------------------------------------------------------------
Step-by-Step Installation Commands
------------------------------------------------------------------------
Open your terminal (Command Prompt, PowerShell, or terminal on macOS/Linux) 
in this project folder and run:

1. Create a Python Virtual Environment:
   python -m venv venv

2. Activate the Virtual Environment:
   * Windows (Command Prompt):
     venv\Scripts\activate
   * Windows (PowerShell):
     venv\Scripts\Activate.ps1
   * macOS / Linux:
     source venv/bin/activate

3. Install All Required Dependencies:
   pip install --upgrade pip
   pip install -r requirements.txt

4. Run the Main Application:
   python main.py

5. Run the System Diagnostics and Tests (Optional, to verify everything works):
   python test_runner.py
   python test_suite.py

------------------------------------------------------------------------
One-Click Shortcut (Windows Only)
------------------------------------------------------------------------
If you are on Windows, we have provided a "run_app.bat" file in the project folder.
You can simply double-click "run_app.bat" to automatically perform the setup,
install dependencies, and launch the application.

------------------------------------------------------------------------
Language & Accessibility Features (Urdu & English)
------------------------------------------------------------------------
- Default Language: Urdu (اردو) is enabled by default across the entire application.
- All UI buttons, labels, indications, and medical data cards display in Urdu.
- Spoken Voice Guidance:
  - Welcome instructions, camera setup, real-time spatial guidance ("دائیں", "بائیں", 
    "سیدھا رکھیں", "دوا بلکل سیدھی ہے"), drug indications, dosage instructions, and 
    precautions are spoken in natural Pakistani Urdu.
- Instant Language Toggle:
  - Click the "🌐 English / اردو" toggle button on screen OR press the "T" key on your
    keyboard at any time to switch dynamically between Urdu and English.
  - The UI and spoken voice immediately switch to your chosen language.

------------------------------------------------------------------------
Keyboard Shortcuts Summary
------------------------------------------------------------------------
- [T]       : Toggle language between Urdu and English (زبان تبدیل کریں)
- [SPACE / C]: Capture bottle label for OCR reading (دوا کا لیبل اسکین کریں)
- [R]       : Retry / Return to live camera feed (دوبارہ کوشش کریں)
- [I]       : Internet fallback search (آن لائن انٹرنیٹ تلاش)
- [U]       : Select Local USB Webcam (لوکل ویب کیم)
- [W]       : Select Wireless IP Camera (وائرلیس آئی پی کیمرا)
- [V]       : Verify camera connection (کیمرا چیک کریں)
- [L]       : Launch dashboard from setup wizard (ڈیش بورڈ شروع کریں)
- [Q]       : Shutdown system workspace (سسٹم بند کریں)
